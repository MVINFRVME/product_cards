# Некорректный вход

Ответы `POST /api/generate` на типичные ошибки. Во всех случаях HTTP 400, карточка не собирается, модель не вызывается. Поле `line` — строка, которую форма подсвечивает в JSON.

## Пустой запрос

Вход:

```text
(пустое тело)
```

Ответ `400`:

```json
{
  "error": "Пустой запрос: вставьте JSON товара или выберите пример."
}
```

## Текст вместо JSON

Вход:

```text
не json
```

Ответ `400`:

```json
{
  "error": "Это не JSON. Данные товара должны начинаться с «{». Нажмите любой пример, чтобы увидеть правильный формат.",
  "line": 1
}
```

## JSON обрезан при копировании

Вход:

```text
{
  "name": "Манометр показывающий DM 02",
  "specs": {
    "диапазон измерений": "0–1,6 МПа",

```

Ответ `400`:

```json
{
  "error": "JSON обрывается на середине: не хватает закрывающей скобки «}» или кавычки. Проверьте, что скопировали его целиком.",
  "line": 4
}
```

## Пропущена запятая

Вход:

```text
{
  "name": "Манометр показывающий DM 02"
  "specs": {}
}
```

Ответ `400`:

```json
{
  "error": "Не получается прочитать JSON: в конце строки не хватает запятой. Строка 2: «\"name\": \"Манометр показывающий DM 02\"».",
  "line": 2
}
```

## Лишняя запятая в конце

Вход:

```text
{
  "name": "Манометр показывающий DM 02",
  "specs": {},
}
```

Ответ `400`:

```json
{
  "error": "Не получается прочитать JSON: название поля должно быть в двойных кавычках, или после последнего поля стоит лишняя запятая. Строка 4: «}».",
  "line": 4
}
```

## Все поля пустые

Вход:

```text
{
  "name": "",
  "manufacturer": "",
  "description": "",
  "specs": {}
}
```

Ответ `400`:

```json
{
  "error": "Нечего собирать: все поля пустые. Заполните хотя бы название прибора или выберите пример."
}
```

## Массив вместо объекта

Вход:

```text
[]
```

Ответ `400`:

```json
{
  "error": "Ожидался JSON-объект с полями name, manufacturer, specs и description."
}
```

## Характеристики списком

Вход:

```text
{"name": "Манометр показывающий DM 02", "specs": ["класс точности"]}
```

Ответ `400`:

```json
{
  "error": "Поле specs должно быть объектом «название: значение», а не списком или строкой."
}
```
